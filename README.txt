LOCALBIZ LAUNCH OS — AUTOCARE DEMO

1. Copy autocare-demo.html into your existing Localbiz-launch project folder.
2. Double-click autocare-demo.html to open it in a browser, or use VS Code Live Server if already installed.
3. Try adding a booking, changing job statuses, searching customers, and submitting the customer booking form.
4. The records are demo-only and stored in this browser on this device using localStorage.

IMPORTANT:
- This is a front-end demonstration, not a production system.
- No shared database, login security, online notifications, payment processing, or backup is connected.
- Sample names and phone numbers are fictional.
- Do not enter real customer data until we add secure authentication and a database.
- The existing index.html and style.css are not changed by this package.
